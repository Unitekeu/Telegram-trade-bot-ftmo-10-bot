# FTMO Pro Bot 🚀

![FTMO Pro Bot](https://github.com/Unitekeu/Telegram-trade-bot-ftmo-10-bot/raw/main/screenshot.png)

**Bot Telegram + MetaTrader 5** για αυτοματοποιημένο trading, σχεδιασμένο για **προκλήσεις FTMO** και χρηματοδοτημένους λογαριασμούς.

Δημιουργεί σημάτα, στέλνει κουμπιά επιβεβαίωσης στο Telegram, εκτελεί συναλλαγές στο MT5 και τηρεί αυστηρά τους κανόνες κινδύνου FTMO.

## Εγκατάσταση

1. Κλώνωσε το repository
   ```bash
   git clone https://github.com/Unitekeu/Telegram-trade-bot-ftmo-10-bot.git
   cd Telegram-trade-bot-ftmo-10-bot
   ```

2. Εγκατάστασε τις εξαρτήσεις
   ```bash
   pip install -r requirements.txt
   ```

3. Δημιούργησε και επεξεργάσου `.env`
   ```bash
   cp .env.example .env
   ```

4. Εκτέλεσε
   ```bash
   python telegram_bot.py
   ```

## Εντολές Telegram

| Εντολή                               | Περιγραφή                            |
|--------------------------------------|--------------------------------------|
| `/start`                             | Εκκίνηση του bot                     |
| `/connect`                           | Σύνδεση με MT5                       |
| `/status`                            | Εμφάνιση κατάστασης και συναλλαγών        |
| `/scan`                              | Σάρωση για νέα σημάτα                |
| `/manual BUY GOLD 0.02 60 120`       | Χειροκίνητη αγορά                    |
| `/manual SELL USDJPY 0.10 80 160`    | Χειροκίνητη πώληση                    |
| `/closeall`                          | Κλείσιμο όλων των θέσεων           |
